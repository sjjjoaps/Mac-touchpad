# MacTouchpad v0.1.7

这一版聚焦三指拖移的稳定性，修复「释放后重新开始」失效，以及拖移过程中误触发点击/双击导致打开文件的问题。

---

### 🌟 重点内容

- **「释放后重新开始」真正生效**：三指拖移中抬起手指后，程序会在 `release_delay_ms`（默认约 500ms）内保持按住；窗口内重新三指按住即可继续拖移，无需重新越过启动阈值。
- **不再误触发点击/双击**：关闭「释放后重新开始」后，拖移过程中手指停顿或触点短暂抖动不会再释放鼠标按键，避免 Windows 把按下/抬起识别为单击、重复触发时双击打开文件。
- **两指续拖**：三指拖移中抬起一根手指，仍可用两指继续拖动；关闭该选项时，仅在剩一根手指或全部离开时结束拖移。

---

### 🐛 修复内容

1. **抬起手指立即松手**
   手势引擎此前在 0/1/2 指帧上直接结束拖移，`release_delay_ms` 没有机会生效。现在这些帧统一交给拖移状态机处理，保持窗口和续拖逻辑正常。

2. **关闭选项后误触点击/双击**
   关闭「释放后重新开始」时，移动过程中仍会以 15ms 周期重启释放计时器；手指停顿即被误判为松手，随后又重新按下，形成点击对。现在关闭该选项时不再启动该计时器，只由真实触点变化结束拖移。

3. **触点抖动导致拖移中断**
   2 指帧不再立即释放按键，避免按压过程中触点短暂抖动造成误松手。

4. **拖移期间误触边缘滑动**
   按住拖移时不再触发单指边缘滑动（音量/亮度）。

### ✅ 验证

- `cargo test -p mac-touchpad-core`：22 passed, 0 failed（新增 6 个拖移状态机用例）。
- 真机验证（Windows 10 19044）：桌面图标与资源管理器内文件的三指拖移、停顿、抬指续拖均正常。

---

### 📦 下载与安装

- 推荐下载下方 `_x64-setup.exe`（NSIS 安装包）或 `.msi`。
- 系统要求：Windows 10 / 11 64 位，支持 Windows 精准触控板（PTP）。

---

### 🚨 升级提醒

- 本版无配置结构变化，`preferences.json` 保持 v10，可直接覆盖安装。
- 安装前请先从托盘退出正在运行的旧版本。
